# Reglas de programación

- Prioriza código simple, claro, legible y funcional.
- Utiliza preferentemente Python y pandas para el análisis y preprocesamiento de datos.
- Organiza los notebooks en celdas con una secuencia lógica y fácil de seguir.
- Evita clases, funciones auxiliares y abstracciones innecesarias. Crea funciones únicamente cuando mejoren la claridad o permitan reutilizar código.
- No agregues dependencias, archivos ni estructuras que no sean necesarios.
- Evita validaciones defensivas excesivas, pero conserva las necesarias para garantizar la integridad de los datos.
- Escribe comentarios en el código únicamente cuando expliquen decisiones que no resulten evidentes.
- Utiliza nombres descriptivos y sencillos para variables y funciones, preferentemente en español.
- Prefiere operaciones vectorizadas de pandas frente a bucles sobre grandes cantidades de registros.
- Cada transformación debe ser comprensible para un estudiante universitario que está aprendiendo minería de datos.
- Utiliza celdas Markdown breves para explicar el propósito de cada etapa y justificar las decisiones metodológicas importantes.
- Nunca elimines, reemplaces ni imputes datos sin justificar el criterio aplicado.
- Conserva intactos los datos originales y documenta las transformaciones realizadas y la cantidad de registros afectados.
- No modifiques archivos ajenos a la tarea solicitada.
- Prioriza siempre la solución más sencilla que mantenga el rigor metodológico.
